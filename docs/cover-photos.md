# 自摄封面与旅行相册

共整理 65 张照片：45 张本地选片、20 张一刻相册原图。原图已核对大小与 MD5；本地选片保留原有构图和调色。网页版本缩放后转换为 WebP，不放大、不额外裁切。

56 张风景、建筑与街景位于 `public/img/covers/`，用于默认文章封面；其余 9 张人物、室内、静物与活动照片位于 `public/img/materials/`，保留在资源相册中。

相册按已知来源分为云南、关西、丰桥、东京、广州和旅途片段。地点不能确认的照片归入旅途片段，不补写具体地点。

完整目录在 `src/data/photo-library.json`，记录照片标题、来源文件名、相册、尺寸和封面用途。资源入口为 `/resource/`，相册页面位于 `/resource/photos/<album>/`。

默认封面按文章顺序从确定性洗牌后的照片中逐张分配。一轮用完再进入下一轮，使各张照片的使用次数最多相差一次。置顶文章先分配，文章列表与正文横幅共用同一分配结果。
