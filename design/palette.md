# 固定主题色

博客的基础色固定为五种。首页、导航、文章列表、阅读页、侧栏和浮层共用这些色源，不再提供调色板。

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 冷纸白 Paper | `#F1F5F9` | 浅色页面背景、深色正文 |
| 纯白 White | `#FFFFFF` | 浅色卡片 |
| 墨蓝 Ink | `#29343E` | 深色页面背景、浅色正文、代码背景 |
| 石蓝 Slate | `#536A80` | 浅色强调、次要文字、控件 |
| 雾蓝 Mist | `#B0C6DB` | 深色强调与次要文字 |

源值集中在 `src/styles/variables.styl`。深浅主题只交换角色；卡片、边线、hover、active、选区与阴影使用五色之间的混合或透明度，不再生成额外色相。旧 `hue` 参数仅保留为组件兼容接口，页面主体色不依赖它。

深色卡片由 92% Ink 和 8% Paper 混合，保留同色系的表面层次。正文仍使用无衬线字体，展示标题与站点框架延续宋体。

## 阅读对比度

以下为 WCAG 相对亮度公式计算的色彩对比度：

| 文字 / 表面 | 比值 |
| --- | --- |
| Ink / Paper | 11.58:1 |
| Slate / Paper | 5.12:1 |
| Slate / White | 5.61:1 |
| Paper / 深色卡片 | 9.15:1 |
| Mist / 深色卡片 | 5.70:1 |

文章中的图片、桌宠立绘、代码语法高亮，以及提示框的成功、注意、警告语义色属于内容，保留各自含义；它们不用于站点导航和表面配色。
